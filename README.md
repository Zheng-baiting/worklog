# 工作记录 · 本机班次工资版

仅在本地维护，不发布 Sites、不上传个人考勤。桌面“工作记录”快捷方式直接打开 dist/index.html。

状态为上班、没上班、加班、中加班、长加班。上午07:50–12:10扣10分钟，下午13:00–17:10扣10分钟，正常白班490分钟；加班包含白班及17:40–21:10，共700分钟；中加班包含白班及17:40–21:40，共730分钟（12小时10分，219元）；长加班包含白班及17:40–22:10，共760分钟。全部按18元/小时计算，即每分钟30分人民币，不按加班加价。

默认统计周期2026-09-17至2026-10-10（含首尾），可修改起止日期。周期合计覆盖整个周期，月份按钮只影响填写区域显示；未来空白日期不推算工资。

本机使用worklog.records.v3保存。迁移时保留v1/v2原始存储，转换后的记录附带previous历史内容。个人初始记录位于被Git忽略的dist/personal-records.js，只在尚无v3记录时应用，后续打开不会覆盖修改。此文件不上传到代码仓库。后续指定记录通过同文件中的 WORKLOG_UPDATES 一次性应用，更新标记与记录一起保存；保留备注和其他日期，后续手动修改不会被重置。

JSON完整备份支持恢复，CSV用于查看周期工资。网页和本地文件使用不同存储，需要时导出再导入。

运行 node --test test.cjs 验证扣休息、工资、周期边界、一次性初始化和存储失败保护。
