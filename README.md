# 工作记录 · 小时工桌面版

本次仅在本地修改，未发布 Sites；线上版本仍为此前的加班记录版本。

- 免登录，桌面“工作记录”快捷方式直接打开。
- 从 2026-09-17 起记录到 2030-12-31。
- 状态：上班、节假日、请假，可留空。
- 填写上下班时间；按实际时间差累计日工时、单月工时和所选月份工时，不扣休息时间。
- 下班时间早于上班时间按次日计算并标注；只填一个时间不计时，相同时间计零。
- 例如 08:20–17:10 = 8小时50分。
- 时间用于计时，状态用于记录；不会按状态自动增减时长。
- 记录保存在本机 localStorage，支持 JSON 导入导出、CSV 导出。

## 历史记录

新格式使用 worklog.records.v2。首次读取可迁移 v1，本机原 v1 数据保持不变。旧“加班”状态在新界面映射为上班，原状态及加班小时保留在完整备份的 legacy 中，不计入新工时。2026-09-17 以前的记录保留在备份中，不出现在当前填写日期内。

网站和桌面文件属于不同存储入口；如需迁移网站中的记录，先从网站导出 JSON，再在桌面版导入。

运行 node --test test.cjs 验证时间计算、起始日、跨天及备份迁移。真实 iPhone 的安装和下载尚未验证。
