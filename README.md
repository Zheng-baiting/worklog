# 工作记录

面向苹果手机主屏幕使用的中文考勤与加班记录应用。

## 当前进度

免登录本机版已实现：打开即用，修改后自动保存在当前设备和浏览器中。用户选择取消登录及跨设备云端同步。手机安装需要先发布 HTTPS 网页；尚未发布。

- 记录范围：2026-09-08 至 2030-12-31，按真实日历生成。
- 在填写页直接多选月份；再点同一个月份即可取消。
- 状态：上班、节假日、请假、加班，可留空。
- 节假日名称支持常用选项及手动输入。
- 只累计手动填写的加班小时，不依赖状态，不计算正常上班工时。
- 单月合计、所选月份合计、JSON 备份合并导入、CSV 导出。
- PWA 清单和离线应用界面；成功缓存后可离线填写。
- 本机持久保存、写入失败提示与重试；无法解析原有记录时停止写入，避免覆盖。

## 本地预览

用任意静态 HTTP 服务器提供 `dist`，或直接打开 `dist/index.html` 预览界面。直接打开文件不会启用 PWA 安装与离线缓存。

运行 `node --test test.cjs` 验证日期边界、加班计算、备份格式校验、持久保存、存储失败保护与备份合并。

本机保存不等于独立备份。更换手机、清除浏览器数据或更换网址前，请导出 JSON 完整备份并保存在 iCloud 等独立位置；新设备打开应用后导入。CSV 是供查看的表格，不能代替可恢复的 JSON 备份。

浏览器实测了填写、刷新恢复、备份合并后刷新保留。尚未在真实 iPhone 上验证安装、离线和系统文件下载；内置预览浏览器未返回下载完成事件，不能将其视为已验证下载成功。

## GitHub 调研

- [amrit-suman/attendance-tracker](https://github.com/amrit-suman/attendance-tracker)：MIT 许可，手机考勤日历、PWA、设备本地 IndexedDB，未提供跨设备同步。功能偏出勤率，不符合只计加班的全部需求。
- [russkyc/timely](https://github.com/russkyc/timely)：移动 PWA，偏上下班时间与 DTR 报表，GPLv3。

本项目按用户实际填写流程独立实现，未复制以上项目代码。

## 数据与公开代码

公开仓库仅包含软件源代码与说明，不包含实际考勤记录、登录凭据或数据库导出。应用没有账号服务、考勤上传接口或统计追踪器。记录以 `worklog.records.v1` 保存在浏览器 localStorage 中；同一设备同一浏览器入口使用同一份记录。
